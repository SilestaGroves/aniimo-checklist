# Aniimo Checklist

Чеклист для игры [Aniimo](https://www.aniimo.com/). Живёт в трее Windows, открывается клавишей `~`.

- **Дейли** — доска активности (шкала 500/700 очков) и ежедневная рутина: Хэтчинатор, Homeland, магазины, дейли ивентов.
- **Викли** — боссы, Companion Handbook, Stamp Rush (1000 штампов), ивенты недели.
- **Ивенты** — все текущие и будущие ивенты: таймеры, расписание, что делать, награды.

- **Погода** — напоминания о погоде: смотришь прогноз в игре (карта → регион → вкладка с солнцем), вписываешь регион, погоду и время.

Напоминания всплывают в правом нижнем углу поверх игры и не забирают фокус. Кроме погоды, чеклист сам напоминает о конце ивентов (по умолчанию за 24 ч и за 3 ч, меняется в ⚙). Ивенты, отмеченные выполненными, пропускаются.

Названия ивентов, анимо и мест — английские (по умолчанию) или официальные русские из клиента: ⚙ → «Названия». Описания всегда на русском. Русские названия берутся из словаря `i18n.ru` в `data.json`; чего там нет, остаётся по-английски.

Отметки снимаются сами в момент сброса на сервере (04:00 по серверу, викли — в понедельник).
Задачи, привязанные к ивенту, видны только пока ивент идёт.

## Запуск

`dist\AniimoChecklist.exe`. При запуске окно показывается, дальше приложение сидит в трее.

| Действие | Как |
|---|---|
| Показать / скрыть | `~` (меняется в настройках) или левый клик по иконке в трее |
| Скрыть | `Esc`, кнопка ✕ |
| Переключить вкладку | `1` `2` `3` `4` |
| Передвинуть окно | Тянуть за заголовок |
| Убрать ненужную задачу | Навести на задачу и нажать × (вернуть можно в настройках) |
| Своя задача | Поле внизу вкладок Дейли / Викли |
| Автозапуск, выход | Правый клик по иконке в трее или ⚙ |

> Игру нужно запускать в режиме «окно без рамки»: поверх эксклюзивного полноэкранного режима Windows оверлеи не рисует.

## Автообновление

Чеклист сам проверяет GitHub (репозиторий `SilestaGroves/aniimo-checklist`) через 10 секунд после запуска и дальше раз в 3 часа. Работает из любой сети, где есть интернет.

- **Ивенты.** Если в ветке `main` лежит `web/data.json` с бо́льшим `revision`, он скачивается и сразу применяется, без перезапуска. Копия хранится в `%LOCALAPPDATA%\AniimoChecklist\data.json`.
- **Приложение.** Если вышел релиз новее установленной версии, всплывает напоминание и появляется кнопка «Обновить». Приложение скачивает zip из релиза, сверяет SHA-256, закрывается, скрипт заменяет файлы и запускает новую версию. Журнал установки: `%LOCALAPPDATA%\AniimoChecklist\update.log`.
- Вручную: ⚙ → «Обновления» → «Проверить сейчас».

Папка с программой должна быть доступна для записи (например, Документы или Рабочий стол, но не Program Files).

### Как выпустить обновление

- **Только ивенты:** поправить `web/data.json`, увеличить `revision` на 1, закоммитить и запушить в `main`.
- **Новая версия приложения:** поднять `<Version>` в `AniimoChecklist.csproj`, закоммитить и запушить, затем `pwsh .\release.ps1 -Notes "Что нового"`.

## Формат данных ивентов

Всё лежит в `web\data.json`. Даты ивентов — даты сервера. Ивент начинается в 04:00 дня `start` и заканчивается в 04:00 дня, следующего за `end`. Главы внутри одного ивента задаются списком `stages`.

## Оформление

Светлая «небесная» тема в духе интерфейса игры.

- Картинки (логотип, баннер, фон, яйца, кубик, иконка-зверёк) взяты с официального сайта aniimo.com и принадлежат Pawprint Studio. Используются только для личного некоммерческого приложения.
- Шрифт Nunito: Google Fonts, лицензия SIL OFL (`web\fonts\OFL.txt`).
- Колокольчик `assets\bell.wav` синтезирован скриптом `tools\make-bell.py`.

## Сборка

Нужен .NET 8 SDK.

```
pwsh .\build.ps1
```

## Где хранятся данные

- Настройки (клавиша, позиция окна, прозрачность): `%APPDATA%\AniimoChecklist\settings.json`
- Отметки: хранилище WebView2 в `%LOCALAPPDATA%\AniimoChecklist\WebView2`
